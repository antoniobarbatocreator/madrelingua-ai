# Madrelingua AI Coach Inglese v1.3

Assistente vocale e testuale per l'apprendimento guidato dell'inglese con Gemini Live, Topic Pack interni e Materiali personali.

Documentazione:

- `docs/PROJECT_HANDOFF.md`: regole autorevoli del prodotto;
- `docs/REBUILD_VERIFICATION.md`: interventi e verifiche realmente eseguite;
- `docs/AI_STUDIO_APPLY.md`: istruzioni di trasferimento in Google AI Studio.

Comandi previsti dopo l'installazione delle dipendenze:

```bash
npm run dev
npm run lint
npm run build
npm run verify:core
```
