# Applicazione in Google AI Studio

Questo progetto è un aggiornamento completo della base ZIP 11. Se AI Studio non accetta ZIP, usare il bundle TXT fornito insieme all'archivio.

Procedura:

1. allegare tutti i file `SOURCE_PART` nella stessa chat;
2. incollare il messaggio contenuto in `00_APPLY_V13.txt`;
3. chiedere la sostituzione esatta dei file delimitati da `FILE START` e `FILE END`;
4. non autorizzare semplificazioni dei Topic Pack o riscritture libere della UI;
5. richiedere build e apertura della preview;
6. eseguire la prova manuale descritta in `REBUILD_VERIFICATION.md`.
